# Faithful Attendance

I want to build an attendance web app where management of a religous education program can log in with google, and access the dashboard with student names and their attendance. I want the student list to be taken from a google sheet (instead of manually imported), and the attendance to be QR Code based, with an option on the dashboard to scan a QR code that is linked with a student and once scanned mark them present/tardy depending on the time. Make the colors be based off of #166534, white, and #ac3725
